# PRAMIO V14.5 — 19 октября 2026

Выпуск объединяет изменения V14.3, V14.4 и текущие исправления портфолио/блога. Production автоматически не менялся.

## Путь к обращению

У каждой из 11 карточек есть два отдельных действия: открыть демонстрацию и «Хочу похожий сайт». Ссылка на демо по-прежнему работает по всей карточке, кроме отдельной кнопки заявки. В форме показывается выбранный пример; его можно убрать. Уже введённое описание задачи сохраняется при выборе другого примера. В письмо добавляются название и ссылка на пример, без изменения SMTP-настроек и защиты формы.

В полноэкранных демо общая навигация также передаёт выбранный проект в заявку. Реальные заявки в ходе проверки не отправлялись.

## Превью и блог

Браузерное измерение старого превью выявило причину: первый экран демо высотой 663,6 px показывался в области 800 px. Новая геометрия начинается с 664 px и уточняется по фактической границе hero после загрузки документа/шрифтов. Лишний фрагмент следующего раздела не должен попадать в карточку. Визуальная приёмка новой версии после установки остаётся необходимой.

Старые слои встроенных стилей главной блога удалены. У карточек естественная высота; будущие пустые темы убраны. Три последних материала на главной и пять MAX-статей доступны ссылками в HTML без обязательного исполнения JavaScript.

## Что проверено и что пока недоступно

- Техническая SEO-основа проверялась ранее: 31 уникальный sitemap URL с HTTP 200, собственные canonical, title/description и один H1; 11 демостраниц с noindex. Это не доказательство фактической индексации.
- Google Search Console потребовал авторизацию; вход не выполнен. Яндекс Вебмастер открыл публичную страницу без отчётов сайта. Количество страниц в индексе, исключения, выбранные поисковиками canonical и поисковые запросы не подтверждены.
- PageSpeed API вернул HTTP 429 (ограничение квоты). Веб-интерфейс не завершил отчёт и после повторного открытия потребовал «Я не робот». Мобильных баллов, LCP, INP и CLS из этого замера нет; они не выдумывались. Незавершённый URL отчёта: https://pagespeed.web.dev/analysis/https-pramio-ru/h8v6txdfbm?form_factor=mobile
- Нужны данные Google Search Console «Индексирование → Страницы», проверка URL главной/услуг/портфолио/статей, статус sitemap; в Яндексе — страницы в поиске/исключённые и диагностика. Продолжить можно через авторизованный доступ либо экспорт этих отчётов.
- После установки нужно отдельно замерить mobile для главной, портфолио и блога в PageSpeed и сопоставить лабораторные показатели с полевыми, если они доступны.

## Пауза публикаций

Поле `publication_paused_after` в `content-queue/articles.json` ограничивает выпуск датой 19.10.2026 00:00 по Москве. Пауза учитывается в ленте, рубрике ТЛЗ, маршруте статей, динамическом sitemap и CLI-публикаторе. Четыре уже опубликованные статьи очереди остаются доступны; шесть будущих не выпускаются автоматически. Исходные тексты и даты сохранены. Для возобновления после устранения пробелов удалить только это поле.

## Установка и приёмка

Сделать резервную копию, распаковать ZIP непосредственно в `public_html` с заменой файлов, сохранить действующий `config.local.php`. В новом архиве приватной конфигурации нет. Подробности — `DEPLOY-V14.txt`.

Проверить на телефоне и desktop: границу первого превью, открытие демо по карточке, отдельный CTA по всем 11 примерам, видимое название в форме, удаление/замену примера без потери текста заявки, компактные карточки блога. Проверить, что CMS V14.4 по-прежнему сохраняет личные товары, а обычная FORMA не применяет эти изменения. Для окончательной проверки состава письма нужен согласованный тест отправки; он в этом выпуске не выполнялся.
