18.10.2026. Production не изменялся. Выпуск полный: 144 файла, распаковка непосредственно в public_html.

## Исправлено

1. **Пропавший заголовок и пустое место после последней карточки.** На production воспроизведено и на desktop: HTML содержит H1 и нижний CTA, но фон Signal Rivers с position:fixed / z-index:0 рисуется поверх статического текста. Карточки с position:relative остаются видны. У gallery-main не было собственного слоя после замены старого контейнера page. Исправлен владелец: gallery-main получает position:relative / z-index:1. Это поднимает весь текст каталога, CTA и пояснение над фоном. Фон и карточки не маскируются новыми !important.
2. **Заголовок раздела:** «Примеры работ», сохранён нативный H1 в исходном HTML.
3. **Синяя рамка «Услуги» при открытии меню касанием.** JS программно переносил фокус на первый пункт при любом открытии, Safari показывал focus-visible. При касании/клике с detail > 0 перенос убран. При открытии клавиатурой / через семантическую активацию detail=0 фокус переносится. Клавиатурный индикатор, Tab и Escape сохранены.
4. Обновлены версии ссылок site-v2.js во всех HTML и PHP-шаблонах, showroom.css в каталоге. Мобильный браузер не должен продолжать использовать закешированную старую версию изменённых ресурсов.
