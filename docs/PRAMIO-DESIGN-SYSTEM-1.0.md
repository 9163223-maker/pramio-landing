# PRAMIO Design System 1.0 — обязательный стандарт

**Введён:** 02.11.2026. **Область:** публичная оболочка pramio.ru — главная, услуги, портфолио, блог, статьи, информационные страницы, а также внутренние шапки и навигация. **Исключение:** самостоятельные демонстрационные сайты, которым нужны собственные бренды и типографика; их внешняя оболочка PRAMIO подчиняется этим правилам.

## Типографика

Допускаются два семейства: **Geologica** (H1–H3, заголовки карточек, крупные цифры) и **Manrope** (обычный текст, меню, кнопки, метаданные, формы).

Все новые общие стили получают размеры из токенов:
- `--pr-fs-meta:14px`: метаданные, категории, теги
- `--pr-fs-ui:16px`: кнопки, меню, второстепенный текст
- `--pr-fs-body:18px`: основные абзацы
- `--pr-fs-card:22px`: заголовки карточек
- `--pr-fs-h3:28px`: подразделы
- `--pr-fs-h2:36px`: заголовки секций
- `--pr-fs-h1:48px`: заголовки внутренних страниц
- `--pr-fs-display:56px`: H1 главной

Типографическая иерархия определяется назначением, а не случайным масштабированием. Текст абзацев — line-height 1.55–1.66. Для статьи — читаемая ширина до 800 px. Не допускать наложения текста при 200% zoom и пользовательских text-spacing overrides (WCAG 2.2, 1.4.4 / 1.4.12).

## Цвета, стекло, отступы

- `--pr-ink:#061833`; `--pr-muted:#4a5b73` — читабельный текст.
- `--pr-blue:#1466ff` — первичный функциональный акцент.
- `--pr-copper:#f28a32` — узнаваемый редкий фирменный акцент, не заменяет синий цвет CTA.
- `--pr-card:rgba(255,255,255,.89)`; `--pr-border:rgba(26,72,125,.13)` — единые подложки и границы.
- Радиус карточки `--pr-radius:24px`; тень `--pr-shadow`.
- Внутренние поля карточки 24–32 px; межкарточный зазор 24 px; секционный ритм 56–72 px.
- Максимальная ширина контейнера 1280 px. Текст не прижимается к границе подложки.
- Одна категория/фильтр = один тип капсулы. Служебная метка = компактный текст с маркером. Не имитировать кнопки неактивными метками.
- На текстовой поверхности фон не должен конкурировать с контентом. Контраст по WCAG AA: обычный текст не ниже 4.5:1, крупный — 3:1.

## Структура контента

- Полный каталог блога находится на `/blog/` с кликабельными HTML-ссылками на **статьи**, а не только на рубрики.
- Рубрики `/blog/tetya-lida/` и `/blog/max/` остаются дополнительно, но не являются обязательными промежуточными шагами.
- Каталог должен быть доступен в исходном HTML без ожидания JavaScript. JS может обновлять список по опубликованным материалам.
- Для новых публичных страниц: собственный SEO-заголовок, canonical, OG JPEG 1200×630, sitemap и доступная навигация.
- Демонстрационные кейсы не выдавать за реальные клиентские проекты.

## Анимация

- Фоновые Signal Rivers: максимум 20 fps на десктопе с точным указателем.
- На мобильных, страницах статей и при `prefers-reduced-motion` — статическое изображение.
- В неактивной вкладке rAF остановлен. Чтение и заполнение форм имеют приоритет перед декором.
- Производительность должна подтверждаться Chrome Performance / Lighthouse; уменьшение объёма работы рендера — не доказательство улучшения Core Web Vitals.

## Правило внесения изменений

Не добавлять новые шрифтовые шкалы/отступы/подложки в HTML или случайный `!important` после канонического блока в конце `site-v2.css`. Изменять дизайн-токены централизованно и проверять производные страницы. Самостоятельные демо не трогать.

**Критерии приёмки:** 1024, 1280, 1440, 1920 px desktop; 390 и 768 px mobile; визуальное сравнение до/после главной, услуг, портфолио, `/blog/`, рубрики и статьи. Отдельно проверить формы, ссылки, производительность и кроссбраузерность. До этого визуальный Gold не подтверждён.
