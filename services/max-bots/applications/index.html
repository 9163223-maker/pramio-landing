Как выглядит путь заявки

Уточнение задачи

Бот задаёт только необходимые вопросы и сохраняет контекст диалога, чтобы менеджеру не приходилось начинать разговор с нуля.

Кнопки вместо лишнего ввода

Callback- и message-кнопки позволяют выбирать варианты, подтверждать действия и двигаться по сценарию без длинных сообщений.

Контакт — когда он нужен

MAX поддерживает кнопку request_contact. Используем её только в сценариях, где номер действительно необходим, и учитываем ограничения платформы на использование полученных данных.

Что проектируем

Сценарий

  • Точки входа и первый ответ
  • Вопросы, кнопки и ветвления
  • Повторный вход и незавершённая заявка
  • Фиксация результата
  • Уведомление ответственного сотрудника
  • Следующий шаг после заявки

Данные и ограничения

  • Собираем только необходимые данные
  • Отдельно согласуем использование номера телефона
  • Проверяем, куда допустимо передавать результат
  • Не считаем запуск бота готовой заявкой
  • Закладываем обработку ошибок и повторов
  • Для production используем HTTPS Webhook

Почему это не просто форма в мессенджере

Ценность появляется, когда бот сохраняет контекст источника, не задаёт человеку лишних вопросов, проверяет обязательные поля и передаёт сотруднику понятный результат. Если для задачи достаточно обычной формы на сайте, предложим более простое решение.
