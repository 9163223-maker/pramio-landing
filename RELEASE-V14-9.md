# PRAMIO V14.9 — два действия в карточке

В каждой карточке портфолио оставлена одна кнопка «Открыть демо» и одна ссылка заявки под описанием. Для сайтов — «Хочу похожий сайт», для CRM/CMS — соответствующая подпись.
Дублирующая кнопка поверх превью удалена из исходного CSS. Превью остаётся кликабельным через ту же основную ссылку. Переход выбранного примера в форму сохранён.

Архив полный. Установка: распаковать непосредственно в public_html с заменой файлов, сохранив config.local.php. Изменения на production автоматически не публикуются.
После установки проверьте две кнопки в карточке и переход по превью. Визуальная приёмка новой версии на телефоне ещё предстоит.
